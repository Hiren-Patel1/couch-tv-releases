# couch-tv, Hub look (unofficial builds)

This repository only holds app files (`couch-tv-home.apk`) for one household's TV. It is **not** the
official couch-tv. The project, its documentation and its official releases are at
**[Seagey/couch-tv](https://github.com/Seagey/couch-tv)**, by Seagey. Please use those.

These builds are couch-tv's TV home with an extra look ("Hub"), signed with a different key from the
official app, so they do not update an official install and the official app does not update them.
No issues or support here; nothing here is endorsed by the couch-tv author.

The apps contain no personal settings: they are built from couch-tv's example settings.
